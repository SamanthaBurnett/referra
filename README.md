# Referra

Referra is a trust-based referral platform where employees who are open to giving referrals can connect with candidates before deciding whether to refer them. Instead of cold requests or blind referrals, Referra focuses on meaningful conversations, transparency, and actionable feedback.

The project is being built incrementally as a production-style portfolio project using Java, Spring Boot, Next.js, PostgreSQL, and AWS.

---

# Motivation

Networking and requesting referrals can feel uncomfortable, especially for people who prefer genuine conversations over cold outreach.

Referra aims to create a space where employees who genuinely want to help can opt in, giving candidates a more welcoming and transparent experience while allowing referrers to make informed referral decisions.

# MVP Goals

The initial version of Referra focuses on the complete referral workflow.

Core features include:

- User authentication
- Candidate profiles
- Referrer profiles
- Resume upload
- Referrer discovery
- Referral request workflow
- Referral outcomes
- Candidate feedback
- Email notifications
